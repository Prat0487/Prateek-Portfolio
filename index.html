01 · AIRBUS

OpenShift → EKS and observability at microservice scale

Problem

Container workloads needed a clearer AWS path — IaC-managed EKS/ECS, serverless event flows, and signals that operators could trust across a large estate.

Approach

Terraform/CloudFormation for AWS foundations; Docker/Jenkins/Artifactory/ECR delivery; OpenShift → EKS migrations; Lambda, ECS Fargate, EventBridge, and Step Functions for event-driven paths; Prometheus, Grafana, Loki, ELK, Splunk, Datadog, and New Relic wired for the runtime.

Outcome

  • Automation spanning 100+ microservices
  • Production container path on EKS/ECS with IaC reviewability
  • Unified observability stack for day-2 operations
  • EKS
  • Terraform
  • Serverless
  • Observability

02 · IBM India (GBS)

Progressive delivery on EKS without blind releases

Problem

Platform teams needed safer production rollouts — blue-green and canary paths, not “deploy and hope” — with messaging and on-call ownership in the loop.

Approach

EKS platforms with Terraform and GitLab CI; Harness/Spinnaker for blue-green and canary releases; Kafka/RabbitMQ in the data path; Splunk/ELK for incident signal; 24×7 on-call for production ownership.

Outcome

  • Blue-green & canary release paths in production
  • Repeatable EKS + Terraform platform foundation
  • On-call ownership tied to real delivery, not handoff theater
  • EKS
  • GitLab CI
  • Harness
  • Spinnaker

03 · GlobalLogic (Hitachi)

GKE golden path with ingress and hardened cloud identity

Problem

Product delivery on GCP needed a packaged cluster path — Helm charts, ingress, CI/CD, and secrets/IAM that teams could reuse without reinventing each sprint.

Approach

GKE with Helm packaging and Kong Ingress; GitLab CI / Cloud Build into Artifact Registry; Harness CD; Pub/Sub; Secret Manager and IAM hardening; ELK/Splunk/Cloud Monitoring for ops visibility.

Outcome

  • Reusable GKE + Helm delivery path
  • Ingress and registry flow teams could adopt
  • Hardened secrets/IAM as default, not afterthought
  • GKE
  • Helm
  • Kong
  • GCP
